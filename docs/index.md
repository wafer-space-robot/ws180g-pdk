# ws180g-pdk documentation

ws180g is a generic, conservative 180 nm process design kit, regenerated end to end from one
"virtual process" description with ranged parameters, open-source TCAD and public measured
data. This is the documentation entry point; later phases extend it.

```{toctree}
:maxdepth: 1

rules
evidence
phase-0-retarget-log
```

The design-rule manual and the evidence margin report are generated by the build:

```sh
uv run ws180g-build --no-container      # out/ws180g005/ and docs/generated/
uv run sphinx-build -W docs out/docs    # this documentation
```

`uv run ws180g-build` without `--no-container` also checks the container image and runs
every per-rule fixture through KLayout and Magic, and every pass fixture, retargeted,
through the public GF180MCU deck. The release tree is `out/ws180g005/` (`libs.tech/klayout/`,
`libs.tech/magic/`, `docs/`); `out/build-manifest.json` lists every output with its
SHA-256, the container image ID and the git commit.
